**Data Analysis Project: Customer & Sales Insights**

This project analyzes customer behavior, sales trends, and operational performance using data visualization and analytics tools.

Objectives:
 -Identify sales trends over time
 -Analyze customer segmentation and repeat behavior
 -Evaluate key business issues like delays and cancellations
 -Build interactive dashboards for business insights
 
Tools Used:
 -Excel (Data Cleaning & Preprocessing)
 -Power BI (Dashboard & KPI Analysis)
 -Tableau (Data Visualization & Storytelling)
 -Data Preprocessing (Excel)

Data was cleaned and prepared using Excel:
 -Removed duplicate records
 -Handled missing/null values
 -Standardized data formats
 -Created calculated columns (e.g., delay category, customer segments)

Note: The Excel file is not included due to file size constraints.

Files in Repository:
 -Power BI Dashboard (.pbix)
 -Tableau Dashboard (.twbx / .twb)

Key Insights:
 -Certain regions have higher cancellation rates
 -Delivery delays significantly impact customer experience
 -Repeat customers contribute a major share of revenue

Dashboards:
 -Power BI Dashboard
 -KPI Cards (Orders, Delay %, Cancellation %)
 -Trend Analysis (Orders over time)
 -Drill-through (Region → Customer details)
 -Tableau Dashboard
 -Customer Segmentation
 -Cohort Analysis
 -Sales Performance Visualization

How to Use:
 -Download the Power BI or Tableau files
 -Open using Power BI Desktop or Tableau
 -Interact with dashboards to explore insights
